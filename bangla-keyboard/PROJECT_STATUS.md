# বাংলা কিবোর্ড প্রজেক্ট — স্ট্যাটাস (v0.1)

তৈরি: Keyman দিয়ে, ক্রস-প্ল্যাটফর্ম (Windows / Linux / macOS / Android / iOS)।
AV ভাইরাস সমস্যা নেই — Keyman ইঞ্জিন নিজেই সাইনড ও বিশ্বস্ত।

## এখন পর্যন্ত যা তৈরি (এবং কম্পাইল হয়েছে)

| অংশ | অবস্থা |
|------|--------|
| টুলচেইন (kmc 18 কম্পাইলার) | ✅ এই সার্ভারে বসানো ও চালু |
| **ফোনেটিক কিবোর্ড** (অভ্র-স্টাইল) | ✅ লেখা + কম্পাইল্ড + ইনস্টলযোগ্য `.kmp` |
| ফিক্সড লেআউট | ⏳ স্ট্রাকচার রেডি, লেআউট-স্ট্যান্ডার্ড তোমার ডিসিশনের অপেক্ষায় |
| অটো-যুক্তাক্ষর (juktakkhor) | ✅ কাজ করছে |
| কার/স্বরচিহ্ন লজিক | ✅ কাজ করছে |

আউটপুট ফাইল: `bangla_phonetic/build/bangla_phonetic.kmp` (এটাই ইনস্টল ফাইল)

### নিয়ম
- পরপর দুই ব্যঞ্জন (মাঝে স্বর না দিলে) → যুক্তাক্ষর। যেমন `kt`→ক্ত
- অন্তর্নিহিত 'অ' চাইলে / যুক্তাক্ষর ভাঙতে `o` দাও। যেমন `kolokata`→কলকাতা

## এখনো যেসব "ফিচার ডিসিশন" তোমার দরকার
1. **ফিক্সড লেআউট স্ট্যান্ডার্ড**: প্রভাত / জাতীয় (Jatiya) / মুনির / কাস্টম — কোনটা?
2. **ক্ষ, জ্ঞ, হৃ (ঋ-কার)** ইত্যাদি স্পেশাল: `x`→ক্ষ, `rri`→ৃ যোগ করবো?
3. **বাংলা সংখ্যা** (১২৩) অটো হবে নাকি ইংরেজি ডিজিট থাকবে?
4. **য বনাম য়**: ডিফল্ট কোনটা `y` তে?
5. অভ্র-হুবহু আচরণ চাও, নাকি এই পরিষ্কার স্কিম ঠিক আছে?
